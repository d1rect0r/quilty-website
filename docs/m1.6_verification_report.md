### B.2 — DynamoDB data-model policy (ADR-0016)

- Three tables: `quilty_website_main` (mega-table) + `consent_current`
  - `consent_audit`.
- PAY_PER_REQUEST billing at Phase 0; DAX deferred to ≥100K MAU.
- AWS-managed key Phase 0; CMK at Phase 1 migration to `marketing-prod`.
- Per-entity access patterns documented in
  `docs/architecture/dynamodb-access-patterns.md`.

### B.1 + B.3 — HTTP client + RFC 9457 (ADR-0017)

- Native `fetch()` + thin Quilty-owned wrapper (no `openapi-fetch`
  runtime adapter).
- Exponential-backoff + full-jitter retry policy (AWS canonical).
- CircuitBreaker port + no-op adapter today; opossum-backed adapter
  shipped as inert skeleton (`makeOpossumCircuitBreaker` throws at
  instantiation; activates at the cascading-failure trigger).
- 12-slug RFC 9457 type registry at
  `packages/api-client/src/domain/problem-types.ts`.
- W3C traceparent injection — vendor-bound active-span read isolated
  to `adapters/otel-traceparent.ts` (ADR-0014 Rule 5).
- UUIDv7 idempotency-key generator (Stripe-canon `Idempotency-Key`
  header).
- TanStack Query v5 wired with React `cache()` server-side singleton
  - browser singleton.
- Sonner toast primitive added via shadcn; `toast.reconnecting()` ready
  for retry-attempt UX wiring at client-composition activation.
- 9-member closed typed-error union (`ApiNetwork` / `ApiTimeout` /
  `ApiHttp` / `ApiProblem` / `ApiParse` / `ApiRequest` / `ApiCircuitOpen`
  / `ApiRetryBudgetExhausted` / `ApiAborted`).

### B.4 — Analytics destinations fan-out

- `AnalyticsDestination` role-shaped union (`product-analytics` /
  `lifecycle-marketing` / `warehouse`) — no vendor names in `ports.ts`.
- `wrapAnalytics` consumes `ReadonlyMap<AnalyticsDestination, Analytics>`.
- Per-destination consent gating with optional override map
  (`consentCategoryByDestination` — runtime-overridable for legal-
  counsel re-classification).
- `Promise.allSettled` fan-out with per-destination failure logging.
- `ctx.destinations` stripped from vendor-facing context before
  adapter.track() (sprint-wide verifier catch).
- Frozen sanitized event prevents adapter in-place mutation cascade.

### B.5 — @quilty/test-fixtures package

- 4 factories shipping: `ContactFormFactory`, `ConsentSnapshotFactory`,
  `AnalyticsEventFactory`, `ProblemDetailsFactory`.
- 5 factories deferred with named triggers (Person / Account / Session
  / Subscription / MfaEnrollment — gate on OpenAPI codegen + Stripe
  bridge + auth-user crate utoipa coverage).
- HIPAA-safe helpers: `safeEmail` (.test TLD), `safePhone` (NANP 555),
  `safeAdultBirthDate` (seeded `faker.date.between`).
- Seed determinism: `setFixtureSeed` pins both integer seed AND
  `faker.setDefaultRefDate` so cross-day reproducibility holds.
- ESLint `no-restricted-imports` bans `@faker-js/faker` outside the
  singleton.
- `ProblemDetailsFactory` re-uses canonical types from
  `@quilty/api-client` (sprint-wide TS-1 fix; eliminates dual-table
  drift risk).

### B.6 — ImagePipeline + Velite schema extensions

- Role-shaped `ImagePipeline.resolve(ImageInput): ResolvedImage` port.
- Adapters: `makeNextImagePipeline` (vendor-bound) +
  `makeInMemoryImagePipeline` (exposed via
  `@quilty/content/testing` subpath — unreachable from production).
- `OptimizedImage` component: discriminated `fill | sized` union;
  Next.js 16 canonical `preload` prop (`priority` is deprecated
  upstream); explicit `quality` field documenting the
  `images.qualities` allowlist requirement.
- `Object.freeze` + `Number.isFinite` invariant guards on the
  shared resolved payload.
- Schema extensions:
  - `Hero.image: ImageDescriptor` (alt REQUIRED per WCAG 1.1.1)
  - `FeatureGrid.icon: IconDescriptor` (discriminated union `kind:
'lucide' | 'image'`)
  - `TestimonialQuote.avatar: ImageDescriptor` (replaces `avatarUrl`)
- BlockRenderer threads optional `imagePipeline` through
  exactOptionalPropertyTypes-safe conditional spread.

### B.7 — CloudFront Functions edge-tier harness

- 3 viewer-response CFFs (single-CFF design — earlier two-CFF stash
  pattern was abandoned for origin-header leak risk):
  - `gpc-force-off.cff.js` — reads `Sec-GPC: 1` directly + writes
    `__Host-quilty_consent` cookie; status-gated to 2xx/3xx.
  - `security-headers.cff.js` — HSTS/COOP/CORP/nosniff/X-Frame-Options/
    Referrer-Policy/Permissions-Policy mirror.
  - `robots-tag-defense.cff.js` — X-Robots-Tag on noindex paths.
- Parity tests import `TAXONOMY_VERSION` + `COOKIE_REGISTRY` from
  `@quilty/consent` + `buildSecurityHeaders()` from `@quilty/security`
  — drift fails CI.
- Regex-drift detection test parses both proxy.ts + CFF source files +
  asserts set equality.
- Cookie `Max-Age=15552000` (180 days) matches `COOKIE_REGISTRY`.
- Activation: DORMANT. proxy.ts remains canonical. README documents
  4-step activation gate (suppress dual cookie write + inject HSTS
  phase at build time + run `aws cloudfront test-function` against
  staging + 1-week soak).

## Sprint-wide cross-commit findings (closed)

The sprint-wide 2-agent sweep surfaced 4 cross-commit issues. All
addressed:

1. **MEDIUM (TS):** `ProblemDetailsFactory` shipped a duplicate
   `ProblemTypeSlug` union + `SLUG_TO_HTTP_STATUS` table that had
   already drifted from `@quilty/api-client`'s `RECOMMENDED_STATUS`
   (consent-required: 403 vs 451; idempotency-key-conflict: 409 vs
   422). Fixed by importing the canonical types/values directly.

2. **MEDIUM (TS):** `ApiClient.request` JSDoc throws-list omitted
   `ApiRequestError` (added in `0ddec6e` Phase D). Updated to list all
   9 members.

3. **MEDIUM (HIPAA/CSP):** `ApiProblemError.message = problem.detail`
   would echo server-supplied free-text into `Error.message` →
   Next.js error boundaries → Sentry `event.exception.values[*].value`
   where key-based PHI scrubbing cannot reliably catch it. Replaced
   with a static template `Problem: <slug> (HTTP <status>)`. Consumers
   that need the detail read `.problem.detail` directly.

4. **LOW (META-2):** Two comment references in
   `wrap-analytics.ts` carried sprint-internal labels
   (`W2.A5 (research wave)` + `Phase A B.4`). Replaced with locked-doc
   references.
