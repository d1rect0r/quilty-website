## Open risks / follow-up notes

1. **CDN dependency in Service Worker.** `apps/web/public/sw.js` loads Workbox from `storage.googleapis.com`. Graceful no-op fallback if unreachable. Self-host migration may be appropriate at first launch — tracked informally; if it bites operationally, raise a TW.
2. **Test-fixtures factory deferred (TW-025).** k6 contact-submission scenario expects pre-signed CSRF + time + captcha tokens; until `@quilty/test-fixtures` ships the load-test factory at M5+, scenario authors hand-roll the JSON.
3. **Cross-repo Flutter pub.dev publish.** `quilty/` Flutter repo doesn't yet consume `@quilty/tokens`. Producer ships at M1.6; first consumer is M3 brand-lock (TW-012).
4. **Step Functions HIPAA wiring.** ADR-0021 documents the S3-URI pattern + CloudWatch log-level constraint, but the actual SST IaC wiring lands at M7 with the first workflow definition (TW-013). A future implementer must read ADR-0021 §HIPAA before touching SFN.
5. **Vaping-cessation positioning vs HIPAA-aligned-mental-health framing in docs.** Repeated framing mismatch in `CLAUDE.md`, strategy doc, roadmap. Out of C+D scope but flagged for a separate doc-reconciliation pass.
6. **No Playwright visual-regression baseline.** D.2(b) adoption commit relies on byte-identical CSS-diff guard (`packages/tokens/__tests__/byte-identical.test.ts`) for migration safety. Visual regression coverage becomes meaningful at M3 visual-identity lock, when actual brand-locked tokens stabilize.
